**应尽早指定一辆实际应用车型或一套自洽的概念车参数**。否则可以计算演示工况，但不能得到可验证的温度和结构最优值。现使用前轴单电机+差速器+左右输出轴摩擦盘，保留后轴常规制动。数值仅为假设。

## P1 提升精度的参数
- 主电机各部件损耗分配、热容/热阻、铜电阻温变和磁钢温度。
- 变速箱齿轮/轴承/搅油损耗，润滑油热容与粘温关系，轴-轴承-壳体热阻。
- 制动盘的材料温变物性、对流系数-转速关系、辐射发射率、非均匀接触热流。
- 气流边界、环境温度、导流罩材料/表面处理、安装公差与热变形。
- 风险分析：制动安全冗余、差速器与输出半轴故障后的制动功能、密封件耐热。

## 参考计算，不是结果
1800kg, 100km/h → 0 的**整车平动动能**（忽略旋转惯量、空气阻力与滚阻）：
`E=0.5*m*(100/3.6)^2 ≈ 694.4 kJ`。
仅做示例，如果前轴分担65%的减速功、前轴没有再生，左右对称则**每侧摩擦接触产生**约225.7kJ；盘片热分配后只有部分热存入盘。不得把225.7kJ直接施加至电机或减速器。实际制动力分配需满足载荷转移和附着、EBD等约束。
