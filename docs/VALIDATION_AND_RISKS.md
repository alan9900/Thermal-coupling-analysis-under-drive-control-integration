# 验证标准、适用边界与风险清单

## 物理检查
1. 运动学：差速器后左右盘转速与对应半轴一致；电机转速约为总速比×车轮平均转速。
2. 机械制动：每个盘接触摩擦功率T×omega非负；再生、后轴、前轴左右分配累计不超过需求并满足附着及扭矩极限。
3. 能量：初末动能差+坡度势能=电池回收+摩擦热+传动/电机损失+行驶阻力及剩余动能；残差和项符号可解释。
4. 热学：节点能量平衡；辐射必须用绝对温标K四次方；传热符号与温差一致；不得无依据忽略盘辐射。
5. 数值：时间步、网格、物性和边界条件敏感性；记录收敛阈值及能量残差，阈值须在看结果前定。
6. 代理模型：训练/独立验证拆分，防止同类重复样本泄漏；NSGA-II Pareto由高保真复核。
7. 工程：制动片摩擦衰退、制动盘热变形、卡钳与支架力、密封圈/润滑油温限、左右独立性、故障后基本制动能力应记录在风险和未来验证中；数值热场不能证明整车制动安全合规。

## 核心风险与对策
| 风险 | 后果 | 控制 |
|---|---|---|
| 缺驱动/再生MAP | 热源预测偏差 | 用来源明确的参数范围；优先求MAP并公布误差预算 |
| 误把全车动能都给两个前制动盘 | 严重高估盘热 | 动态轴荷+前后制动力+再生分配 |
| 忽略输出轴和轴承固体热路 | 低估电驱吸热 | 对流、辐射、固体导热分别统计 |
| 隔热阻碍盘冷却 | 盘过热/热衰退 | 将盘温及热变形列为硬约束 |
| 假定左右盘绝对对称 | 忽略非对称导流及卡钳热负荷 | 后期加左右扰动/偏载验证 |
| 再生制动按恒定比例假定 | 高SOC/低速下不可信 | 限制函数并做regen=0兜底 |
| 过度CFD计算 | 进度失控 | 热网络+有限数量局部CFD+代理模型 |
| 论文复现与新构型混淆 | 创新边界不清 | 将原文仅作为方法学对照，注明研究对象不同 |
| 无实测却称验证 | 学术不规范 | 明确 numerical cross-validation 与 experimental validation 的区别 |

## 论文预期贡献（需要结果证实）
(i) 量化不同工况的多热源耦合和热侵入路径；
(ii) 给出能权衡电驱热防护与盘散热的定向隔热导流罩；
(iii) 可复现地报告多目标结构优化及不确定性范围。
**不预先保证降温幅度、首创性或期刊等级**。
