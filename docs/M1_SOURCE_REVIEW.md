## 为什么采用总损耗约束下的参数化分配

现有实测参考不足以辨识全部内部损耗。直接叠加一套假设的3RI²、铁损和器件损耗到EPA损耗上，会重复计热；直接用这些假设项替换联合图，也会改变已核验功率账本。因此保留联合总损耗及传动总损耗，用物理形状权重决定其空间分配。归一化因子逐时输出，显示原始权重与可用总损耗的差距；这是一种**守恒的S3工程分配**，不称为已标定的绝对铜耗模型。

当前实现范围：铜耗权重包含真实参考电阻、假设转矩/电流换算、弱磁电流增量及AC速度项；铁损权重为频率一/二次项，在固定极对数与假定磁密下用转速比例近似；转子/其他项将速度平方和负载杂散合并，**不能解读为独立磁钢涡流损耗**。逆变器在驱动凸包内使用既有估计比并扫描传递倍率，在再生及凸包外使用显式S3比例。未建立缺乏器件数据的绝对开关/通态损耗公式。

减速器使用负载功率比例、等效摩擦转矩×输入角速度及速度三次的油液/风阻形状权重；三次项是固定阻力系数近似下的探索性形状，**不是复现Corley文中的搅油关联式**，未知油深、黏度、齿轮直径及雷诺数效应不被隐藏。保留0.96方向效率给出的总热预算，空载真实搅油/拖曳仍未计入。

## 参数区间与可追溯性

`configs/m1_source_partition.yaml` 是独立工程场景；16个参数均记录下界/候选/上界及单位（字段后缀）。**所有数值区间均为S3探索性选择，不是论文给出的MG2标定区间或概率分布。** 它们用于判断结论是否依赖内部热分配；不能保证真实部件一定落在区间内。物理规律或真实电阻有资料支持，不会自动提高整条预测的来源等级。

| 参数组 | 区间/候选 | 选择依据与尚缺证据 |
|---|---|---|
| 转矩常数代理 | 0.50/0.70/0.90 Nm/Arms | S3改变电流平方权重；不是IPMSM唯一转矩电流曲线，需要d/q电流与磁链标定 |
| 绕组温度 | 40/100/140°C | S3冷/热电阻场景，无温度反馈；不代表安全温限 |
| AC铜耗速度项、弱磁电流项 | 0/0.15/0.40；0/0.30/0.80 | S3是否计入及增量变化；缺频域电阻/电流控制图 |
| 6000rpm铁损一/二次权重 | 80/200/400 W；50/150/350 W | S3权重范围，非叠片材料测试。6000rpm只作尺度坐标 |
| 转子速度平方、100Nm杂散权重 | 20/70/180 W；10/30/100 W | S3合并项，不能据此局部加载全部到磁钢 |
| 驱动逆变器比倍率、回退逆变器比 | 0.8/1/1.2；0.05/0.15/0.35 | S3跨来源转移与未知再生拆分；驱动比例限制在0.01–0.99，保证正热量 |
| 齿面系数、轴承负载系数 | 0.010/0.020/0.035；0.001/0.003/0.006 | S3总预算内分配，缺摩擦系数、齿形与轴承载荷 |
| 轴承等效转矩、密封等效转矩 | 0.02/0.06/0.12 Nm；0.005/0.020/0.050 Nm | S3合计折算到电机轴；不是某轴承目录数据 |
| 6000rpm搅油/风阻权重 | 10/50/150 W | S3速度三次权重，未知温黏与浸油深度 |
| 盘热比例 | 0.85/0.90/0.95 | S3候选敏感性区间，不是实测置信区间；实际材料确定后应重新评估 |

替代与升级路线：取得电流、温度与电阻数据后可替换铜耗代理；取得磁链/损耗分离测试后替换铁/转子权重；取得真实负向功率与器件损耗后替换再生拆分；取得两级齿轮几何、轴承选型、油温黏度后替换减速器形状。升级必须重新检验联合能量预算，不能在旧总损耗之上另加一份。

真实温度验证仍缺热容、热阻、冷却及接触参数，归属M2及后续阶段；本次只说明未来概念计算所需边界，不执行温度求解。
