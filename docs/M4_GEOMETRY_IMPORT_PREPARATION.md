# M3交付内的未来ANSYS准备清单

本文件属于M3几何复核，不表示已启动M4。ANSYS导入、网格、边界求解、Fluent均NOT EXECUTED。

1. 接收`cad/m3_review/Case{0,A,B,C}_d50_thermal.step`，以完整装配作空间核对。45mm保留失败对照。按step_manifest验证哈希、mm单位、各体体积与命名；不得自动合并材料或填补0.5mm片隙。
2. 分出盘/帽、毂、可拆连接套、轴、轴承等效区、支架、分体箱、适配器、铁心、绕组、转子其他、水库存和油库存。一体小齿轮用source_regions表的x平面切分，保存其整体连续导热。
3. 按`configs/M3_to_M4_mapping.json`单侧热源合同加载；原W积分归一到子体W/m³。逆变器外部记录；总损耗只校验，不能再叠加；不把转子其他全部映射为磁体。齿轮空间分配及盘/片热量分配是工程假设，按相关场景扫描。
4. `contact_pairs.csv`和`supplemental_contact_pairs.csv`提供名义共形面积/间隙。绕组端环/芯、套/轴、键、滚动轴承、油膜、盘/片、支架、箱体分型面分别设定；实际h保持null。不以全部自动bonded替代缺失数据。套压力/热松脱与罩滑移支点在机械冻结前均BLOCKED。
5. 轴承环为包络，不能按实心钢密度获得真实C；需目录或样机有效质量及等效接触模型。材料温变、接触压力和油膜均没有标定。封闭水套无实际端口，不是已定义液冷系统。
6. 表面选择按`boundary_selection_plan.csv`的几何谓词，避免脆弱的面编号。名义接触面不能同时做外部对流；总表面积含内面。盘面可用分项体源，或另定义两侧摩擦面归一热流，不能两者重复。
7. 辐射温度用K且允许反向，当前F只覆盖盘后露出环→箱体指定端面；完整面间交换及罩再辐射仍需建模。CaseC局部空气域仅通过连通检查，来流、反向冲刷、旋转域、远场范围和网格独立性未执行。
8. 真正获批进入M4后，必须检查瞬态储能、环境/冷却带走能量与热源整体闭合、网格与步长收敛，并报告接触/C/冷却/总损耗不确定性。在此之前不能发布温度预测或方案降温排序。
