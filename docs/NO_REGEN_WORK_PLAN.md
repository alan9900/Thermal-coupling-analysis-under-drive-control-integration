本轮仅授权调整计划、更新文档、提交当前开发分支和更新PR。**仿真工作继续暂停；没有研究者新的执行命令，不改动可执行模型、生成新热源、重新划分网格、启动MATLAB/ANSYS/Fluent求解或开展优化。** 不合并M4、不创建M4-v1.0、不进入M5。后续恢复计算以研究者明确命令为准；恢复再生研究也须另行明确指示。

当前M0—M3已按各自限定概念范围归档；M4为PARTIAL，分支`stage/M4-ansys`、草稿[PR #5](https://github.com/alan9900/Thermal-coupling-analysis-under-drive-control-integration/pull/5)。本计划对后续任务范围的规定优先于旧计划中再生功率、SOC禁充、低速再生退出等工作安排。历史来源审计和固定版本中的再生内容继续保留用于追溯。

## 3 零再生工况的物理约束

后续实施时须明确关闭左右再生使能，指令再生制动转矩为零，牵引系统向电池的再生回收功率为零。电池充电能力在新场景中设置为0只是禁用再生的控制边界，不能改写成电池真实接受能力已知。原始未知参数仍保持null/NaN。SOC、充电能力和低速再生退出不再作为后续主要仿真变量。

制动需求仍由动态轴荷、附着约束、道路阻力及前后轴分配确定。前轴及左右后轴共同承担制动；不可把整车动能全加载到单侧后盘。对称时后轴需求各半，单盘与本侧车轮同速，不再乘9倍速比。

若以减速度大小a、路阻F_road和车速v表示，平路筛查可采用以下定义；实际实现须保持与整车动力学一致：

$$
f_r=f_{r,0}-\frac{a}{g}\frac{h}{L},\quad
F_b=ma-F_{\mathrm{road}},\quad
F_{\mathrm{fric,side}}=\frac12 f_r F_b,\quad
P_{\mathrm{fric,side}}=F_{\mathrm{fric,side}}v
=T_{\mathrm{disc}}\omega_{\mathrm{wheel}}.
$$

此式假定制动力需求为正、左右对称、未额外引入拖曳端口；若添加拖曳或旋转惯量，须同步修订整车账本，避免与摩擦制动重复扣除。未满足附着或制动力需求的轨迹应标为不可行，不强制解释为实现的减速度。

盘/片热量名义90%/10%仍为S3候选；后续验证其敏感性。热流施加到两侧摩擦环及对应摩擦片，保留功率、面积和热量积分核对。

**零再生不等于旋转中的电机和减速器物理损耗必为零。** 驱动预热阶段仍用M1电机分项及减速器损耗；进入制动阶段后，电机按零再生控制状态确定损耗。当前M1对未通电电机及零传递功率的处理省略了部分空载拖曳、搅油等损耗，后续必须显式报告这一近似，必要时另设有来源及范围的独立候选，不把省略值称为实测零损耗。

不能同时施加原再生铜耗，又把全部后轴需求加载为摩擦制动。不能为制造高温而在制动阶段任意保留高负载驱动热源。预热形成的温度场应连续传递到制动与冷却阶段；电机既有储热与新制动热的耦合是研究主线。逆变器仍独立记账，转子/其他损耗不全部解释为永磁体发热。

## 4 恢复执行后的工作顺序

下列任务全部为**PLANNED / NOT EXECUTED**。顺序不等于执行授权，不承诺未经计算的温度或降温幅度。

| 顺序 | 工作内容 | 应交付证据与关卡 |
|---|---|---|
| P1 | 建立独立零再生场景与M1派生热源 | 左右再生关闭、指令再生转矩与回收功率为0；前轴及两侧后轴总能量闭合；新场景ID、参数、来源和输入哈希 |
| P2 | 生成与新场景一致的M2对照 | 复用固定版本代码方法，在新配置及新目录输出；与M4比较时明确几何热容、护罩/空气节点和边界差异，不覆盖M2-v1.0 |
| P3 | Case0零再生单次制动及预热后制动 | 先得到可控单次基准，再以连续温度场连接驱动预热和制动；输出全体28热区最高温度、热容均温、峰值时刻和完整时序 |
| P4 | 数值与热源不确定性验证 | 新热源下重新核对网格、时间步、能量；特别检查盘/片厚度、内部发热区域、预热阶段步长，以及接触、冷却、盘片分配、总损耗误差 |
| P5 | 热耦合归因与重复零再生制动 | 用同一几何、边界、时序的匹配对照隔离摩擦热影响；再逐步增加制动次数及观察时长，检查轴承、油液和壳体热量积累 |
| P6 | M4报告、验收表及PR复核 | 旧含再生结果与新零再生结果分开；记录未知量、实际完成/失败/未执行项；经研究者批准才合并及打正式Tag |

80 km/h、0.6g可作为与旧结果比较的首个候选；100 km/h及0.3g/0.8g可用于后续范围研究。初速、减速度、预热负荷与时长、循环次数/间隔、冷却体温及允许温度须在恢复执行时逐项登记，当前没有新增冻结的工况数值。60 kW参考峰值不能作为持续预热能力证明。

### 热源对照组

为避免与几何Case A/B/C混淆，新工况建议采用以下独立标识。具体模型和文件目前均未生成。

| 场景标识 | 目的 | 设置原则 |
|---|---|---|
| NR-I | 内部损耗对照 | 与配对NR-C相同车速、转速、控制及边界，仅关闭摩擦热的热学诊断；不是声称无摩擦仍可完成零再生减速 |
| NR-B | 零再生制动热单独作用 | 冷态或登记的共同初态，只保留摩擦热，用于热学归因 |
| NR-C | 零再生共同作用 | 同一物理时序下电机/减速器允许的损耗与摩擦热共同作用，禁止叠加不相容负荷 |
| NR-P | 驱动预热后零再生制动 | 连续保存并传递全部节点/有限元初始温度；重点观察盘、轴承、油液、壳体和绕组的滞后响应 |
| NR-R | 重复零再生制动 | 在单次基准数值验证后开展；驱动、制动、静置/冷却段分别记账 |

## 5 重点输出与验收解释

1. 全体28个现有热区均保存温度时序；重点分析制动盘、盘毂/套筒、输出轴及两轴承、两级齿轮、油液、前后壳体、电机壳体、定子、绕组和转子等效区。报告节点最高温度、热容加权平均、峰值时刻及相对各段初态的温升。
2. 输出同一时刻的整体温度场和各部件独立峰值图，写明时刻、单位、色标及来源等级；区域独立峰值不拼成同步温度场。体积平均、局部峰值及热容均温分别说明。
3. 制动附加温升用相同内部损耗和边界的配对场景计算，非线性情况下不把分别求解的温升直接线性相加。不同热史或不同初态之间的差值不解释为唯一制动贡献。
4. 辐射、固体导热分别保存瞬时有符号热流、累计正向流入和净热量；轴/轴承串联截面不重复相加。壳体净辐射包含开口环境时，不能直接称为完全分离的盘—壳体交换。
5. 环境对流散热与制动热空气回流分开定义。当前M4未求解热空气回流，标为NOT MODELLED；相关流动和热空气路径只在后续获准的M5研究，不能用当前模型的缺失项作物理零值。
6. 总体能量必须闭合源项、实体储热、环境散热、液冷和净辐射；同时检查电驱子域。源项分配守恒不能替代热网络或有限元整体收支。
7. 大温升不作为选取工况的目标，温度低也不等于隔热有效；需要能量、热容、时间尺度和边界证据。真实材料、接触、温变、损耗及冷却未标定时，仍按工程假设和范围报告，不声称实物温度精度或机械安全认证。
